# Гипотезы и условия до новых запусков

Дата: 1 ноября 2026. Это запись до сравнения трёх learning rate.

H1 (ретроспективный разбор уже выполненного пользователем опыта): на малом train при длительном обучении train BCE падает, validation BCE после минимума растёт. Возврат лучшего checkpoint уменьшает validation BCE по сравнению с последними весами. Этот результат уже известен из присланного лога: H1 не выдаётся за новую предрегистрацию.

H2 (до новых запусков): при одинаковом бюджете 300 full-batch обновлений LR=0.0001 может давать недостаточное обучение. LR=0.001 или 0.01 может уменьшить и train, и validation BCE. Это проверяется результатами, не предполагается гарантированным. Если улучшения нет, гипотеза не подтверждается.

Условия: HIGGS; исходное разбиение70/15/15 seed12; первые100000 train, round(validation_size*100000/full_train_size) validation/test; scaler fit только train; сеть28→32→16→1, ReLU, Adam; seed модели12; без dropout/weight decay; эпох300; меняется только LR:0.0001,0.001,0.01.

Baseline: LogisticRegression(max_iter=1000,random_state=12), default L-BFGS и регуляризация; тот же train/validation. Главный критерий выбора сети — минимальная validation BCE, задача бинарная, threshold0.5; дополнительно F1, ROC-AUC, accuracy, precision, recall.

Test не используется для выбора LR. После выбора — оценка выбранной сети и baseline на одном test. Test уже просматривался в истории проекта: итог не называется оценкой на никогда не использованном holdout. Новые изменения после test не подбираются.

Один seed — требование пользователя. Не заявлять доказанную устойчивость между инициализациями. Изменения числа строк не считать чистым сравнением моделей на одном validation.
